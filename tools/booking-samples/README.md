# Booking samples

Made-up Airbnb emails and a calendar file, for testing `bookings.py` with no Airbnb account.
They are written from what hosts report about Airbnb's emails, not copied from a real one.
Run `.venv/bin/python tools/booking_test.py` from the guest-tv folder.

Expected: Nov 2 Sarah (3 guests, matched by code), Nov 12 gone (cancelled), Nov 20 Priya
(2 guests, matched by date), the shop email ignored.
